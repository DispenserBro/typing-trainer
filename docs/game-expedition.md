# Игровая экспедиция: бой, маршруты и проверка

## Игровой цикл

Новый забег строит карту с 4–6 промежуточными колонками между боссами и 3–5 вариантами в ширину. Верхний путь чаще даёт восстановление, нижний — риск и элитные встречи, центральный зависит от региона. Перекрёстные связи позволяют менять маршрут, но не каждую ветку можно сменить в любой момент. Перед боссом доступны подготовка, добыча и опасная встреча.

Четыре региона повторяются: роща, архив, кузня и разлом. Они меняют распределение комнат и оформление карты. Карточки ближайших шагов показывают эффект встречи и типы следующих узлов; наведение или фокус подсвечивает связи.

Уровень боя определяется глубиной колонки, а не очередью распределения между параллельными ветвями. Все боевые узлы имеют `battleLevel`; маршруты не должны вести к меньшему уровню. Последняя схватка сама является финалом: дополнительного дублирующего босса нет. Номер уровня означает глубину прогресса, а не количество посещённых комнат.

## Встречи и последствия

`src/core/game/expedition.ts` содержит восемь вариантов: источник, святилище, библиотека, караван, кузнец, алхимик, алтарь и резонатор. Каждый предлагает три выбора. Есть лечение, ремонт, артефакты, увеличение максимального HP, регенерация и временные модификаторы с преимуществами и штрафами.

Цена и длительность указаны до выбора. Покупка за HP недоступна, если оставит игрока без здоровья. Ненужное чистое лечение и ремонт отключаются; из события можно выйти без сделки. Модификаторы используют существующие коэффициенты, складываются с экипировкой и расходуют длительность после боя. Регенерация восстанавливает 10 HP после победы.

Победа над элитой даёт выбор постоянного предмета или 20 HP; мини-босс — артефакта с прочностью или 30 HP. Босс до финала предлагает три награды, среди которых гарантирован предмет. Вес отдельного предмета по редкости 1/2/3 равен 6/3/1; это веса предметов, а не фиксированные вероятности целой категории.

## Боевая математика

`battleSystem.ts` отделён от React; RNG передаётся аргументом для воспроизводимых проверок.

- Атака и защита чередуются; в обычной фазе 8 слов, у босса 10.
- Отношение CPM к эффективной цели ограничено диапазоном 0–2. Модификаторы цели ограничивают её множитель диапазоном 0,5–1,5.
- Точность участвует и в уроне, и в защите. Пустая атака или нулевая точность не наносят урон.
- Броня уменьшает урон в процентах, максимум на 75%; она больше не вычитается как абсолютные HP.
- Ритм: `3 / (1 + standardDeviation / averageInterval)`; длинные паузы не отбрасываются.
- Вероятность крита ограничена 50%, уклонения — 35%. Крит удваивает урон; успешное уклонение отменяет входящий удар.
- HP врага растёт как `baseHP * (1 + (level - 1) * 0.018)`, уровень ограничен 1–100; у босса дополнительный множитель 1,15.
- При таймауте вклад скорости умножается на долю набранного текста.
- Элитная схватка определяется типом врага; номер уровня, кратный пяти, сам по себе не превращает её в босса.

Новые предметы: «Сердце метронома» (крит и урон), «Шаг сквозь туман» (уклонение и защита), «Пробивающее перо» (снижение брони и добавочный урон).

## Интерфейс и сохранения

`GameCombatBurst.tsx` рисует 10–18 CSS-частиц для удара, крита, защиты, уклонения и победы. Они не перехватывают ввод, не используют постоянный цикл JavaScript и отключаются через reduced motion приложения или ОС. Числовая обратная связь остаётся видимой и доступна через live region.

Перед следующей фазой есть пауза 650 мс. Таймер очищается при уходе, рестарте и смене состояния. Подсказка продолжения не должна закрывать активный текст.

Используется существующий формат `GameRunMapState`, `GameRunEventState`, `BattleState`, `GameRunModifier` и наград; новые поля публичного SDK не добавлены. Сохранённая старая карта не перестраивается. Новые развилки появляются в новом забеге.

`appGameRunResolvers.ts` сохраняет все существующие боевые коэффициенты, знаки штрафов, `maxLifeDelta`, `fullHeal` и `regenTurns`. Раньше нормализация отбрасывала эти поля или обнуляла отрицательные значения; проверка теперь проходит через `normalizeSavedGameRunState`. Уже утраченные в старом сохранении значения автоматически не восстанавливаются.

Вариант встречи и предмет определяются ID узла; предложение целиком сохраняется. В ежедневном режиме также фиксируются параметры врага, боевые броски и выбор наград. Генерация текста и все старые fallback-события не объявляются полностью детерминированными.

## Проверки

Из корня приложения:

```powershell
npm run build
npm run diagnostics:quick
npm run diagnostics:game-balance -- --runs 80
npm run diagnostics:i18n
npm run diagnostics:perf-budget
```

`combatBalanceDiagnostics.ts`: 4 800 схваток на уровнях 1/5/25/50/100, четыре типа врага, три профиля набора; регрессии формул и наград.
`expeditionDiagnostics.ts`: 200 карт, достижимость, единственный финал, отсутствие циклов, последовательность уровней, все восемь вариантов событий, безопасная цена и сериализация.

UI проверять на отдельном профиле: новый забег, выбор ветки, эффект события, бой с несколькими фазами, элитная награда, сохранение/перезапуск, reduced motion, узкое окно. Перезапускать приложение с временным `appPath/data`; смены только Electron `userData` недостаточно для изоляции прогресса в dev.

Ограничения: симуляции отдельных схваток и генератора не доказывают идеальный баланс всей кампании. Legacy-отчёт случайных событий не симулирует новую карту. История/результат боя пока показывают метрики завершающей фазы, а не агрегат всех фаз. Установщик и релизные платформы этой проверкой не покрываются.
