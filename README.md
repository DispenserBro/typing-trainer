# Typing Trainer

`Typing Trainer` - десктопный клавиатурный тренажёр для русского и английского языков. Приложение помогает тренировать скорость, точность, устойчивость набора и работу с разными раскладками.

## Возможности

- Тренировка набора текста с постепенным открытием символов.
- Режимы практики, спринта, survival и flawless.
- «Хранитель слов» — приключение на Phaser: три класса, 15 шагов по трём регионам, тактические бои набором слов, реликвии и постоянные улучшения. [Правила игры](docs/game-adventure.md).
- Классический игровой режим с прежней экипировкой, daily/ghost, достижениями и поддержкой расширений.
- Статистика скорости, точности, истории сессий, проблемных символов и раскладок.
- Достижения, цели, недельные задачи и рекомендации.
- Приветственные гайды для режимов при первом запуске.
- Центр расширений с источниками, аддонами, модификациями и темами.
- Поддержка Markdown-карточек для описания дополнений.
- Настройка темы приложения и встроенный редактор тем.
- Локализация интерфейса и встроенных ресурсов.

## Языки и раскладки

| Язык | Раскладки |
| --- | --- |
| Английский | `qwerty`, `dvorak` |
| Русский | `йцукен`, `яверты` |

Русские словари поддерживают режим работы с буквой `ё` и без неё.

## Установка

Основной вариант для Windows — **portable ZIP без установки**. Скачайте файл
`Typing-Trainer-<version>-win-<arch>-portable.zip` на [странице релизов](https://github.com/DispenserBro/typing-trainer/releases/latest),
полностью распакуйте его в отдельную папку с правом записи и запустите `Typing Trainer.exe`.

Прогресс и расширения сохраняются в `data` рядом с EXE. Для обновления закройте приложение,
распакуйте новую версию в новую папку и скопируйте туда прежнюю `data`.
Автоматическая установка обновлений в portable отключена. При переходе с установленной
версии можно так же перенести её `data`. [Подробная инструкция](docs/windows-portable.txt).

Windows SmartScreen может показывать предупреждение и для portable EXE.
ZIP не заменяет цифровую подпись. Если вы доверяете файлу из нашего репозитория,
на экране SmartScreen обычно доступны «Подробнее» → «Выполнить в любом случае»;
на управляемых компьютерах запуск может ограничиваться политикой организации.

Обычный установщик остаётся дополнительным вариантом.

На Windows используется `Typing-Trainer-<version>-win-<arch>.exe`. Установщик использует стандартный мастер NSIS с системным оформлением и выбором каталога установки. Первичная настройка выполняется в самом приложении после запуска. При удалении пользовательские данные и статистика сохраняются по умолчанию; удалить их можно отдельным флажком в мастере деинсталляции.

## Запуск из исходников

Если приложение запускается из репозитория:

```bash
npm install
npm start
```

`npm start` собирает приложение и запускает Electron из текущей рабочей копии.

## Сборка

```bash
npm run build:win
npm run build:linux
npm run build:mac
```

Готовые артефакты создаются в `dist-build`. Значок `data/app-icon.png` должен быть квадратным и не меньше 512×512 для macOS. Команда `npm run render:icon` формирует PNG 1024×1024 из исходного `data/app-icon.svg`.

Перед релизом локально должен проходить полный gate:

```bash
npm run diagnostics:release-hardening
```

Он запускает production build, debug diagnostics, content-pipeline, perf budget, Electron platform smoke, packaging dry-run и, если SDK checkout доступен, gate отдельного SDK (`npm ci`, `npm run smoke`, `npm pack --dry-run`). По умолчанию SDK ожидается в `../SDK`; в CI путь задаётся через `TYPING_TRAINER_SDK_DIR`.

GitHub Actions выпускает Windows (основной portable `zip` и дополнительный `exe`), Linux (`AppImage`, `deb`, `rpm`) и macOS (`dmg`, `zip`), а также метаданные автообновления. Публикация начинается только после platform-smoke, release-hardening и успешной сборки всех платформ. Windows tag-release собирается без обязательной подписи; если заданы secrets `WINDOWS_CSC_LINK` и `WINDOWS_CSC_KEY_PASSWORD`, workflow дополнительно проверяет Authenticode-подпись `.exe`. macOS-пакеты выпускаются без подписи и notarization; система может потребовать разрешить запуск вручную. Если задана variable `SDK_REPOSITORY`, workflow дополнительно checkout-ит публичный SDK-репозиторий и включает SDK gate.

Установленное приложение проверяет стабильные GitHub Releases после запуска, скачивает обновление и предлагает перезапуск. При откладывании установка выполняется после закрытия приложения. Проверка отключена в Windows portable ZIP (по файлу `typing-trainer-portable.json` рядом с EXE), при запуске из исходников и в platform-smoke; поддержка установки зависит от формата пакета. Полный переход между версиями требует отдельной проверки на установленном приложении.

## Расширения

Центр расширений поддерживает внешние источники контента. Через него можно устанавливать:

- аддоны с дополнительными словарями, уроками, раскладками, предметами и достижениями;
- модификации с расширенным доступом к API приложения;
- темы оформления приложения.

Источники могут предоставлять карточки описания в Markdown, чтобы пользователь мог посмотреть описание пакета перед установкой.
